# ECV 后端封版演示种子脚本（USD 数字版，2026-11-04 行为实测）

数字唯一来源：`scripts/calc_demo_numbers.py`。该脚本直接调用前端 `/api/v1/plans` 所用的
`generate_dual_plans(intent_query="ECV 社团采购", max_items=8, use_channel3=False)`，
并断言下表全部数字（跑一次即可复核）：

| 项 | 值 |
|---|---|
| 主线预算 | $600 |
| 方案 A（低价优先） | 8 件 / $26.0 |
| 方案 B（耐用优先） | 8 件 / $393.0 |
| 兜底触发预算 | $350（< B 的 $393.0） |
| D2 主门超支 | $43.0（$393.0 − $350.0） |
| 删 3 件后总价 | $285.0（$393.0 − $108.0） |

注意事项：
- 商品池为 K1 45 件（价格 $1.5–$95，含环保标记）；planner 固定取 8 件（`max_items=8`）。
- 兜底在"支付前 D2 主门"触发：购物车 $393.0 > 预算 $350.0 → HTTP 400 `budget_violated`。
  （plan 阶段 planner 会重新组装到预算内，所以"压低预算"本身不会产生无解；无解只在预算 < 最低单价 $1.5 时出现，状态 `budget_too_low`。）
- 每句话术标注预期系统反应：前端出现什么、总价变成多少、审计新增哪条事件。

================================================================================
## 6 步主线话术

1. "帮我选 8 件商品，总价控制在 600 美元以内"
   → 前端：生成双方案 Tab。A 低价优先 8 件 $26.0；B 耐用优先 8 件 $393.0。审计新增：`plan_generated`

2. "选方案 B"
   → 前端：购物车 8 件，总价 $393.0
     （丝绸丝巾 95.0 / 软木板 30x40cm 55.0 / 有机棉托特包 48.0 / 铝制水杯 500ml 45.0 /
       玻璃水瓶 750ml 42.0 / 木质相框 8x10 38.0 / 铝制奖牌 35.0 / 亚麻收纳袋 35.0）
     审计：`select_plan` 仅入车，不单独写事件

3. "预算压到 350"（兜底分支触发）
   → 前端：新增预算约束 350；点"确认支付"时被 D2 主门拦截，返回
     HTTP 400 `budget_violated`：cart_total 393.0 / budget_limit 350.0 / overage 43.0，
     文案"🚨 预算守卫拦截支付：超支 43.00，已超过预算上限 350.00。"
     审计新增：`constraint_changed` + `budget_violated` + `fallback_triggered`

4. "删掉木质相框、铝制奖牌、亚麻收纳袋"
   → 前端：购物车 8 件 → 5 件；删减 38.0 + 35.0 + 35.0 = 108.0，
     总价 393.0 − 108.0 = 285.0（≤ 350）。审计新增：`cart_modified`

5. "恢复预算到 600"
   → 前端：预算 350 → 600；285.0 ≤ 600，预算守卫通过。审计新增：`constraint_changed`

6. "支付确认"（触发 PayPal）
   → 前端：弹出 PayPal Sandbox 窗口；按钮下方小字"人工确认后方可发起支付"。
     审计新增：`review_confirmed` + `order_status_changed(confirmed→paying)`；
     浏览器批准回调后：`payment_completed` + `order_status_changed(paying→paid)`

================================================================================
## 兜底分支数值（实测）

- 触发预算：$350（Plan B 购物车 $393.0，超支 $43.0）
- 拦截响应：HTTP 400，`detail.status = "budget_violated"`
  - `detail.cart_total` = 393.0，`detail.budget_limit` = 350.0，`detail.overage` = 43.0
  - `detail.fallback` / `detail.message` = "超支 43.00，已超过预算上限 350.00。"
- 修复动作（`/api/v1/cart/modify` 实测）：删除
  `k1_031 木质相框 8x10 ($38.0)`、`k1_007 铝制奖牌 ($35.0)`、`k1_044 亚麻收纳袋 ($35.0)`
  → 删减合计 $108.0，新总价 $285.0（5 件）
- 另一条无解路径（plan 阶段）：预算 $1.0 < 最低单价 $1.5 → `status=budget_too_low`，
  文案"⚠️ 预算过低，连单件商品都无法满足。当前预算：1.00 最低商品单价：1.50"，
  建议两条："提高预算" / "减少采购数量"
